BikSAFE comparison tools

The November 2 model and pipeline changes have not been tested. Use a stationary setup for the first checks.

Choose a model

  • COCO Lite: main-thread baseline
  • COCO Lite: Worker preprocessing
  • EfficientDet-Lite0: experimental Worker, about 4.6 MB
  • RF-DETR Nano: experimental Worker, about 56 MB

For the synthetic camera, add &demo=1 to an app link. This checks the pipeline; it does not measure detection accuracy.

Evaluation

  • Public-image model evaluator
  • COCO Worker smoke check
  • COCO baseline backend benchmark: 1,000 runs per engine

In the app, use Menu → Diag Stats → Record timings, then Export timings. Reports identify the requested and active model, runtime, backend and build fingerprint.
